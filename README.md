# Alan San

Desarrollador Frontend en Guadalajara, México.

## Lo que hago

Construyo interfaces que se ven bien y funcionan mejor. No creo en la dicotomía entre diseño y código: ambos son parte del mismo problema.

Mi portafolio tiene auroras boreales animadas en el fondo. No porque sea necesario, sino porque me pareció interesante. Esa es mi forma de trabajar: si algo merece estar ahí, tiene que estar bien hecho.

## Cómo trabajo

**Diseño primero.** Figma es donde resuelvo problemas antes de escribir una línea de código. Si la idea no está clara ahí, no estará clara en el navegador.

**Código limpio.** TypeScript strict, componentes pequeños, una responsabilidad cada uno. Prefiero refactorizar tres veces a mantener código que me da vergüenza leer.

**Performance real.** No adivino tiempos de carga: mido. Si algo parece lento, añado instrumentación antes de optimizar.

## Stack

**Todos los días:** React, Astro, TypeScript, Tailwind CSS, Figma

**Cuando hace falta:** Node.js, PostgreSQL, APIs REST, GSAP, Three.js

**Despliegue:** Vercel y Netlify, según lo que pida el proyecto
